# Otto's Groove Lab

Otto the octopus teaches you to make music with code. Snap together colourful blocks, hear the groove, watch the wave, and see the real [Strudel](https://strudel.cc) code appear, so what you build today plays the same when you paste it into strudel.cc.

## Develop

```sh
npm install
npm run dev
```

Other scripts: `npm test`, `npm run lint`, `npm run typecheck`, `npm run build`.
